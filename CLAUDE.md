# CLAUDE.md

- Whenever you finish a task and write a summary of the implemented changes, include the name of the build that contains those changes, for example `build-30-1bca82e` (`build-<N>-<commit>`: `<N>` is the GitHub Actions workflow run number and `<commit>` is the first 7 characters of the commit hash; see [Labels](README.md#option-1-github-actions-no-mac-needed)).
- Comments, Markdown files, and the names of classes, functions, instances, methods, etc. must be in English. User-facing text in the app is not covered by this rule.
